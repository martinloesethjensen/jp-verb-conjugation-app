# Counters: Milestone 1 (Reference and Playground) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Counters tab opens on a grid of counting groups (Drinks, People, Days & dates, …). Each group opens a lookup table comparing its counters for 1–10 and 何. There are 18 N5 counters. Each counter page shows its readings with the sound changes marked, what it counts, examples and traps, and a "Count them" playground. One search covers groups, counters, counted forms (3本, さんぼん, sanbon) and things ("umbrella" → 本).

**Architecture:** Readings are generated by `scripts/update_data.py` into a new signed `data/counters.json` from each counter's sound class plus author overrides, the same way adjective forms are generated into `words.json`. VerbKit decodes and syncs the file with a copy of the words pattern (`CountersManifest`, `CountersSyncService`, a one-row `CountersEntity`, `CountersStore`). The app adds a fourth tab. It only reads readings and the `changed` keys and never computes a reading itself.

**Tech Stack:** Python 3 standard library (data pipeline), Swift 5 mode, SwiftUI (iOS 26), SwiftData, XcodeGen, XCTest, `unittest`.

**Spec:** `docs/superpowers/specs/2026-10-17-counters-design.md` (milestone 1 only).

**Base:** `main` with the spec merged. Branch: `claude/counters-reference`.

- The app never derives a reading. Ruby for a reading comes from `counters.json`, never from `FuriganaDictionary`. Speech uses the kana reading, never the kanji.

```python
# --- Counters (counters.json) ---------------------------------------------

COUNTER_KEYS = [str(n) for n in range(1, 11)] + ["what"]
SOUND_CLASSES = ("plain", "k", "s", "h-b", "h-p", "irregular")
COUNTER_FITS = ("primary", "acceptable", "casual")
BASE_NUMBERS = {"1": "いち", "2": "に", "3": "さん", "4": "よん", "5": "ご", "6": "ろく",
                "7": "なな", "8": "はち", "9": "きゅう", "10": "じゅう", "what": "なん"}
# The small-っ form of the numbers that can geminate (いち -> いっ).
GEMINATED = {"1": "いっ", "6": "ろっ", "8": "はっ", "10": "じゅっ"}
GEMINATING_KEYS = {"k": ("1", "6", "8", "10"), "s": ("1", "8", "10"),
                   "h-b": ("1", "6", "8", "10"), "h-p": ("1", "6", "8", "10")}
# は-row counters: the keys that voice to b or p without gemination.
VOICED_KEYS = {"h-b": {"3": "b", "what": "b"}, "h-p": {"3": "p", "4": "p", "what": "p"}}
HA_ROW = {"は": ("ぱ", "ば"), "ひ": ("ぴ", "び"), "ふ": ("ぷ", "ぶ"), "へ": ("ぺ", "べ"), "ほ": ("ぽ", "ぼ")}


def _voiced(reading, kind):
    """ほん -> ぽん (p) or ぼん (b)."""
    p, b = HA_ROW[reading[0]]
    return (p if kind == "p" else b) + reading[1:]


def counter_readings(counter):
    """Every key's readings, preferred first: the class's rule, then the author's overrides.
    An irregular counter's readings are its overrides."""
    sound, reading = counter["sound"], counter["reading"]
    overrides = counter.get("overrides", {})
    if sound == "irregular":
        return {key: list(overrides[key]) for key in COUNTER_KEYS}
    result = {}
    for key in COUNTER_KEYS:
        plain = BASE_NUMBERS[key] + reading
        if key in GEMINATING_KEYS.get(sound, ()):
            rest = _voiced(reading, "p") if sound.startswith("h-") else reading
            readings = [GEMINATED[key] + rest]
            if key == "8" and sound != "s":
                readings.append(plain)        # はちほん, はちこ are heard too
            if key == "10":
                readings.append("じっ" + rest)
        elif key in VOICED_KEYS.get(sound, {}):
            readings = [BASE_NUMBERS[key] + _voiced(reading, VOICED_KEYS[sound][key])]
        else:
            readings = [plain]
        result[key] = readings
    for key, value in overrides.items():
        result[key] = list(value)
    return result


def changed_keys(counter, readings):
    """The keys whose preferred reading is not the base number plus the counter's reading."""
    if counter["sound"] == "irregular":
        return []                     # every cell differs; a tint on all of them says nothing
    return [key for key in COUNTER_KEYS if readings[key][0] != BASE_NUMBERS[key] + counter["reading"]]
```

### Task 7: Counter search

**Files:**
- Create: `.../Search/CounterSearch.swift`
- Test: `CounterSearchTests.swift`

**Interfaces:**
- Produces:

```swift
public struct CounterFormMatch: Equatable, Sendable {
    public var counter: Counter
    public var number: CounterNumber
    public var reading: String          // the accepted reading that matched, or the preferred one
}

public struct CounterThingMatch: Equatable, Sendable {
    public var thing: CountedThing
    public var counters: [Counter]      // every counter listing this word, primary fit first
}

public struct CounterSearchResults: Equatable, Sendable {
    public var groups: [CounterGroup]
    public var counters: [Counter]
    public var forms: [CounterFormMatch]
    public var things: [CounterThingMatch]
    public var isEmpty: Bool
}

/// Searches everything in the Counters tab. Each section keeps data order.
public func searchCounters(_ counters: [Counter], groups: [CounterGroup], query: String) -> CounterSearchResults

/// "3本" -> "三本", "10本" -> "十本", "何本" unchanged. Full-width digits too. Only 1-10.
func kanjiNumerals(in query: String) -> String
```

Matching rules:
- The query is trimmed. English matches are case-insensitive. Romaji is converted with `Romaji.toHiragana`, with spaces removed.
- **Groups:** `title` or `summary` contains the query (English), or the group has a member counter that matches as a counter.
- **Counters:** `counter` equals the query, `reading` equals the hiragana query, or `meaning` contains the query.
- **Forms:** the query (after `kanjiNumerals`) equals `counter.written(number)`, or a hiragana query of at least 2 kana is a prefix of one of the readings at that number. Every accepted reading counts, so はちほん finds 本 at 8. Cap the section at 20 rows.
  - さん on its own would match every counter at 3, which is noise. A hiragana query only matches forms when it is longer than the base number it starts with: さん matches nothing, さんぼ matches 本 at 3.
- **Things:** word equals, kana equals the hiragana query, or meaning contains the query. One row per distinct word, with every counter that lists it.

  - an empty query gives empty results (the home screen shows the grid instead)
  - "3本", "３本", 三本, さんぼん, "sanbon" and さんぼ each give one form, 本 at 3
  - はちほん → 本 at 8 with reading はちほん
  - "drinks" → the Drinks group; "glasses" → Drinks through its summary
  - "hon", ほん, 本 → the counter 本, and no form rows
  - "umbrella", "kasa", 傘 → thing 傘 with [本]
  - "rabbit" with 匹 (acceptable) and 羽 (primary) → one thing row listing [羽, 匹]
  - さん → no form rows
  - `kanjiNumerals`: "1本" → 一本, "10本" → 十本, "11本" is unchanged
